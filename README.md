## 🎨 Design Features

- **Deep purple-black theme** (`#0a0118`) with violet/gold accents
- **Video-background heroes** on every page
- **5-currency pricing** (ZAR, USD, GBP, EUR, NGN) with live switcher
- **Fully responsive** — mobile, tablet, desktop
- **Self-contained** — no build tools, no frameworks, no dependencies
- **Sticky navigation** with blur backdrop
- **Animated elements** — fadeUp, float, pulse glow
- **Accordion FAQs** and **filterable course grids**

## 🚀 Quick Start

1. Download all files to a folder
2. Double-click `index.html` to preview locally
3. All navigation works relative — no server required
